# Logística Fácil

Sistemaaa de gerenciamento logístico desenvolvido,, como atividade prática orientada (APO) do curso de Engenharia de Software da Universidade Paranaense (UNIPAR).

## Objetivo

Desenvolver uma aplicação web para gerenciar produtos, endereços, transportadoras e fretes, permitindo também a geração de relatórios.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- PHP
- MySQL
- Bootstrap 5
- XAMPP
- Git e GitHub

## Funcionalidades

### Produtos
- Cadastrar produtos
- Editar produtos
- Excluir produtos
- Listar produtos cadastrados

### Endereços
- Cadastrar endereços de origem e destino
- Editar e excluir endereços

### Transportadoras
- Cadastrar empresas transportadoras
- Editar e excluir transportadoras

### Fretes
- Cadastrar fretes
- Selecionar transportadora, origem e destino
- Adicionar vários produtos dinamicamente com JavaScript
- Editar e excluir fretes
- Acompanhar o status do transporte

### Relatórios
- Consultar fretes por data
- Visualizar produtos e transportadoras
- Consultar status dos fretes
- Exportar relatórios em CSV
- Imprimir ou salvar relatórios em PDF

## Como executar

1. Instalar o XAMPP.
2. Colocar a pasta logistica-facil dentro de htdocs.
3. Iniciar Apache e MySQL no XAMPP.
4. Criar o banco de dados MySQL e suas tabelas.
5. Configurar a conexão em config/conexao.php.
6. Acessar http://localhost/logistica-facil/.

Observação: a estrutura do banco de dados precisa estar configurada para executar o sistema.
